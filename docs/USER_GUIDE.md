# Tutor and learner guide — Course Report

## Tutors

1. Open the course that contains the SCORM activities.
2. In the **Course Report** block, open the course report.
3. Use the filters (company, % passed, minimum score, threshold status) to narrow the list of learners.
4. Expand a learner to see the detail of each SCORM activity. For packages with several SCOs, expand the activity to see each SCO, and the test answers where available.
5. Use the column selector to choose the optional columns shown on screen and in the exports. Your choice is remembered.
6. If your role allows it, export the report to Excel or PDF, or print the compliance evidence of a learner.
7. If your role allows it, send a reminder to the selected learners and check the reminder log.
8. Open **Tutor activity** to see the activity of the course tutors and print the connections PDF.

The values shown depend on what each SCORM package reports to Moodle.

## Learners

If the site allows it, the Course Report block shows learners a link to their own progress. Learners only see their own data; the full course report is only for authorised staff.

## Exports

Exported files can contain personal data. Store them securely and share them only with authorised people.

## Reminders

Reminders are sent by email, Moodle message or both, depending on the site configuration. Automatic reminders depend on Moodle cron and on the administrator's settings.

## Reading the figures

- A package with several SCOs counts each SCO as one topic.
- The score is the mean of the SCO scores and may differ from the package's weighted grade.
- The threshold status compares the % of SCOs passed with the threshold set by the administrator.
- SCORM time is the time reported by the package, not necessarily the real time spent studying.

If a value looks wrong, contact the course tutor or the Moodle administrator with the course, activity and attempt.
